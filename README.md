\# 🎓 Student Analytics Pro



An AI-powered student performance tracking and analytics dashboard built with \*\*Streamlit\*\*, \*\*Python\*\*, and \*\*Machine Learning\*\*.



It helps schools and teachers to monitor student performance, attendance, risk analysis, and AI-based grading insights in real-time.



\---



\## 🚀 Features



\### 📊 Student Analytics

\- Total marks calculation (Maths, Physics, Chemistry, English)

\- Average score computation

\- AI-based grade prediction

\- Performance improvement tracking



\### 🧠 AI Intelligence

\- Smart grade prediction using custom AI engine

\- AI score evaluation system

\- Student risk detection (weak students identification)

\- AI insights dashboard



\### 📡 Live Dashboard

\- Real-time auto refresh system

\- Live notifications system

\- Role-based access (Admin / Teacher / Student)



\### ⚠ Risk \& Alert System

\- Low attendance alerts

\- Weak student detection

\- Emergency exam mode for critical students

\- Performance drop warnings



\### 💬 Communication System

\- Student testimonials system

\- Feedback submission panel

\- Live notification feed



\### 📈 Visualization

\- Bar charts (Performance comparison)

\- Pie charts (Grade distribution)

\- Attendance charts

\- Top performers leaderboard



\### 📄 Reports

\- Download student report in PDF

\- Export data in CSV format

\- Class-wise filtering system



\### 🤖 AI Chatbot

\- Student assistant chatbot for queries

\- Smart data-based responses
